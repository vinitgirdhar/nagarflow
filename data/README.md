# Reference and synthetic data

- `mmr_311_complaints_50k.csv`: bundled synthetic complaint history used by the
  reproducible intelligence evaluation.
- `nagarflow_dataset.csv`: development sample dataset used by explicit demo
  initialization utilities.
- `areas.txt`: locality reference retained from the original prototype.

These files are not verified live municipal records. Normal application setup
does not automatically import the CSVs into operational stores. See
[Evaluation](../docs/EVALUATION.md) for methodology and limits.
